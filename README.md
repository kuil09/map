**완전한 601개 마커 지오메트리 백업은 없습니다.** 전체 지도 607/601/6은 기존 저장·재로드 영수증 기준이며 새 전체 조회 결과가 아닙니다. 최신 38행 추가 시도는 2026-10-27 약 06:52 UTC에 기존 목적지 데이터 표를 열던 중 브라우저 렌더러 오류 9로 중단되었습니다. 가져오기 창·파일 선택·업로드·저장에 도달하지 않았고 쓰기·불확실한 쓰기는 모두 0건입니다. 기존 607행 교체용 파일이 아닙니다.

v37은 익산 나바위성당·홍천 수타사·정선 정암사/수마노탑 3곳을 추가합니다. 왕송호수캠핑장은 운영기관 매표소 도로명주소 **왕송못동로 295**를 현재 주소 검색용으로 반영하되 이전 지번을 다섯 언어 참고사항에 보존합니다. 화랑오토캠핑장에는 **2026-11-09~13 배수로 정비 공사**를 기록하며 전체 휴장으로 해석하지 않습니다. 종료된 10월 19~26일 후문 통제는 현재 통제로 표시하지 않습니다. 다섯 장소 모두 좌표·거리 미확인 상태를 유지합니다.

기존 960개 출처 객체, 변경되지 않은 643개 장소, 원래 311개 장소와 사진·역사 자료는 보존됩니다. **v37은 기준 저장소 준비 상태이며 사이트 배포·지도 반영은 아직 아닙니다.** 현재 사이트는 [v36 게시·검수 기록](data/history/site-deployment-v36.json)에 근거합니다. 기존 35행 및 38행 CSV는 불변 보존하고 새 41행 후보를 제공합니다. 35/38행을 수동 업로드했다면 중복 방지를 위해 실제 지도 상태를 먼저 대조해야 하며, 겹치는 파일을 함께 가져오면 안 됩니다.

## 사용

Python 3 표준 라이브러리만 필요합니다. 네트워크 호출·지도 업로드·사이트 배포는 자동으로 하지 않습니다.
역사적 바이트 회귀 검증에는 v35·v36 기준 커밋을 포함한 로컬 Git 이력이 필요합니다. 테스트는 누락된 이력을 네트워크에서 자동으로 가져오지 않습니다.

```sh
python scripts/validate.py
python -m unittest discover -s tests -v
python scripts/build_exports.py --out build
python scripts/build_site_data.py --out build/site-data
```

기존 사이트 사진이 있는 빌드 디렉터리로 자산 무결성을 추가 확인할 수 있습니다.

```sh
python scripts/validate.py --asset-root PATH_TO_SITE_BUILD
```

## 구조

- `data/places.json`: 장소 ID, 5개 언어 설명, **완전한 원 주소**, 현재 출처 상태, 좌표·미확인 사항. 앞으로의 편집 기준.
- `data/photos.json`: 실제 사진 출처·저자·라이선스·변경 내용·32개 파일 해시 및 장소 연결. 사진 파일은 기존 사이트에 그대로 둡니다.
- `data/research.json`: 현재 사이트가 읽는 검증 범위·변경 이력·거리 기준·열린 문제. 현재 영업 보증이 아닙니다.
- `data/map/`: 607행 역사적 원 필드, 정확한 ID 연결, 6개 미해결, 변경 대기 및 불완전한 좌표 증거.
- `data/history/`: 원 Source audit **296개 문자열과 SHA-256**, 적용 변경, 실패 기록, 검증 이력.
- `exports/map-append35-v35.csv`: 검토된 35행 **주소 기반 추가 전용** 파일. 좌표 열과 Source audit 열 없음.
- `exports/map-append38-v36.csv`: 불변 보존한 38행 **주소 기반 추가 파일**. 최신 자동 업로드 시도는 쓰기 0건으로 중단되었습니다.
- `exports/map-append41-v37.csv`: 현재 41행 **주소 기반 추가 후보**. 35/38행과 겹치므로 수동 업로드 여부를 먼저 대조해야 합니다.
- `data/history/batch19-change-record.json`: 이번 변경·보존 범위와 공개 출처 검토 자료의 해시. 비공개 작업 자료는 포함하지 않습니다.
- `schemas/`, `scripts/`, `tests/`: 계약·결정적 산출물 생성·검증.
