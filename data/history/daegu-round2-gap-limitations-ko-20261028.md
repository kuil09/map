기준 커밋은 kuil09/map main 875f1951입니다. 지도 편집, 업로드, push, 외부 연락은 하지 않았습니다. 이미 지도에 있는 8개 ID는 다시 넣지 않았습니다. places.json(648건)과 이름 기준으로 대조했을 때 대구 중복은 없었습니다.

## 공통 한계
- 모든 후보는 **주소만** 있습니다. 좌표를 추정하지 않았고 coordinates는 null입니다. 입구, 주차, Camp Walker 게이트 기준 거리와 소요시간은 측정하지 않았습니다. 그래서 초안 CSV에서는 좌표 열을 뺐습니다.
- 사진: 재사용 라이선스를 확인한 사진이 없어 넣지 않았습니다.
- 외국인 관련 사항(온라인 본인인증, 회원가입, 해외 카드, 영어 응대)은 공식 출처에 명시된 경우를 빼고 모두 '미확인'입니다.
- 영업시간은 공식 페이지에 게시된 값이며 실시간 영업 여부가 아닙니다.

## 음식·카페 (검증 5 / 보류 2 / 제외 0): 2차 보강 완료
- 검증: 낙영찜갈비 본점. 대구관광 공식 페이지 기준이며, 휴무일은 미확인입니다.
- 보류: 미도다방. 공식 페이지 본문 열람이 HTTP 400으로 실패했고, 시간이 09:00과 09:30 두 가지로 엇갈립니다.
- 추가 검증(대구푸드 대구10미 본문을 2026-10-28에 직접 열람): 마시불 동대구 본점(송라로 55), 동봉 범어점(범어천로 128), 버들식당(두류공원로28길 8), 남문납작만두(명륜로 64-1)를 추가했습니다.
  - 공식 출처가 확정하는 것은 지점, 주소, 전화, 휴무일뿐입니다. **영업시간은 비공식 자료 기준**이며 기록에 그렇게 표시했습니다.
  - 현재 영업 여부는 공공 인허가 자료 미러와 2025~2026년 비공식 목록으로 보강했습니다. 업소 공식 사이트는 없거나 접속이 안 됐습니다(성주막창 사이트 503).
  - 마시불의 휴무일은 이전 색인본(첫째·셋째 일요일)과 현재 페이지(매주 일요일)가 다릅니다. 현재 페이지를 채택했습니다.
- 미성당은 제외에서 **보류**로 바꿨습니다. 대구푸드는 명덕로 93, 대구관광은 남산로 75-1로 안내하고, 2025-02-04 폐업 기록도 있어 이전했을 가능성이 있습니다. 지점과 주소를 확정해야 합니다.
- 제외: 팔공막창. 공식 출처 두 곳의 주소가 동성로6길 46과 42-5로 달라 후보로 채택하지 않았습니다.
